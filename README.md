# 🏏 Virat Kohli Showcase | King Kohli Legacy Portal

An interactive web showcase and career analytics portal celebrating cricket legend **Virat Kohli**. Built with **React**, **TypeScript**, **Three.js**, and **Tailwind CSS**, featuring 3D trophy rendering, career milestones, and seamless **Google Drive** integration.

---

## ✨ Features

- **🏆 Interactive 3D Trophy Showcase**: Real-time 3D rendering powered by Three.js with full mouse/touch rotation control, auto-rotation toggles, particle sparkles, and custom materials (Gold, Platinum, Emerald).
- **📊 Career Metrics & Statistics**: Comprehensive breakdown of Test, ODI, T20I, and IPL statistics with interactive sorting and format filters.
- **⚡ Quick Milestone Counters**: Highlights key records like 26,900+ international runs, 50 ODI centuries, and 80 total centuries.
- **📜 Hall of Fame & Iconic Records**: Detailed scorecards and retrospectives on milestone innings (e.g., 50th ODI 100 at Wankhede, 183 vs Pakistan).
- **📁 Google Drive Integration**: Authenticate with Google OAuth to upload files, manage documents, search workspace assets, and store personal notes directly in Google Drive.
- **🎨 Modern Dark Theme Aesthetics**: Geometric layout design paired with Orbitron display typography and subtle ambient glow effects.

---

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **3D Graphics**: Three.js / WebGL
- **Authentication & Storage**: Firebase Auth & Google Drive API
- **Icons**: Lucide React / Heroicons
